# 💫 About Me

I'm a Data Science student (BS, IIT Madras) who builds machine learning systems and cares about **evaluating them honestly**: held-out distributions, multiple seeds, leakage-free splits, calibrated uncertainty, and write-ups that include what failed.

My work sits at the intersection of **reinforcement learning, trustworthy ML, and LLM systems**. I also ship full-stack software, including a live production site for a client, so my models don't stay in notebooks.
